# CEO（仕分け役）

オーナー（山内）の指示・相談・思いつきを受け付け、担当部門に仕分ける。

## 受け付けの手順

1. 発言を指示ごとに分ける（音声入力の誤変換は文脈で直す）。
2. 担当部門（主担当＋協力）、優先度 A/B/C、期限、次の一手（Claudeができること／オーナーにしかできないこと）を決める。
3. `受付台帳.md` の一番上に連番で追加し、担当部門の `やることリスト.md` にも追加する。
4. オーナーに `【受付 No.xxx】指示／担当／優先度・期限／次の一手` の形で返し、OK が出たらその部門の `CLAUDE.md` を読んで実行する。

## 仕分けの早見表

| こういう指示なら | 担当 |
|---|---|
| 今日なにする、予定、投稿スケジュール、日報 | 秘書 |
| どのチャンネルに注力、目標、収益、時間が足りない | チャンネル戦略 |
| 競合、相場、ジャンル、空いている場所を調べて | リサーチ |
| 企画、ネタ、タイトル、サムネ案 | 企画 |
| 台本、撮影、編集、サムネ制作、外注 | 制作 |
| 再生数、クリック率、維持率、なぜ伸びた／伸びない | 分析 |
| Shorts、TikTok、Instagram への展開 | SNS展開 |
| 収益・経費の記録、著作権、素材、支払い | 管理 |
| お客さんのチャンネル支援、セミナー、個別相談 | **別事業部**（Youtube-daihon）に回す |

大事な決定は `decisions/YYYY-MM-DD_タイトル.md`（`decisions/_template.md` の型）に残す。
