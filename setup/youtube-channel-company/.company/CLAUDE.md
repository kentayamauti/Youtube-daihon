# YouTubeチャンネル運営事業部（.company）

オーナー自身のYouTubeチャンネル（とTikTok・Instagram）を運営し、伸ばす事業部。
ここで得た実績・ノウハウは、コンサル・セミナー事業部の「教材・事例」になる。

## 体制

```
社長／オーナー（山内）……指示を出す・最終判断をする
   │
CEO（Claude）……指示を受け付けて、担当部門に仕分ける（ceo/）
   │
   ├─ 秘書（secretary/）……今日やること、日報、投稿スケジュールの見張り
   ├─ チャンネル戦略（strategy/）……どのチャンネルに力を入れるか、目標・収益・時間配分
   ├─ リサーチ（research/）……競合・ジャンルの相場・空いている場所の調査
   ├─ 企画（planning/）……企画会議、タイトル・サムネ案、企画ストック
   ├─ 制作（production/）……台本、撮影・編集の段取り、サムネ制作、外注管理
   ├─ 分析（analytics/）……再生・クリック率・視聴維持率の振り返り、改善案
   ├─ SNS展開（sns/）……Shorts・TikTok・Instagramへの展開
   └─ 管理（admin/）……収益・経費の記録、著作権・素材の管理、外注の支払い
```

各部門のフォルダに `CLAUDE.md`（役割と進め方）、`やることリスト.md`、`_template.md`（成果物の型）がある。

## 毎日の流れ

1. **朝**：秘書が「今日やること（最大3つ）」をつくる（`/kyou`）→ `secretary/日報/YYYY-MM-DD.md`
2. **日中**：オーナーの指示をCEOが受け付け、部門に仕分ける（`/shiwake`）→ `ceo/受付台帳.md`
3. **各部門が実行**：Claudeができること（リサーチ・企画案・台本・分析）はオーナーの OK の後に進める
4. **夜**：秘書が締める。大きな決定は `ceo/decisions/` に残す

## 基本の考え方（セミナーで教えていることを自分でも守る）

- 自分のやりたいことではなく、視聴者が求めることを再現する。
- 企画の前にリサーチ（ジャンルの相場・競合・空いている場所）。
- 続けられるペースが最優先。1日に詰め込むのは最大3つ。

## 優先度

- **A**：期限3日以内／投稿予定日に直結／お金・権利に関わる
- **B**：今週中
- **C**：アイデア置き場
