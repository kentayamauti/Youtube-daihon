# 個人・家族の発信（チャンネル運営）

対象例：グローバルハーツ㈱（女性が一人で、または夫婦・家族で撮影している Instagram / YouTube）

## 見立て

- **ykkn 山内さんの得意分野**
- 一番重要なのは**目的**
- **再生数や登録者を増やしたいなら、今のやり方はやめたほうがいい**
  - 視聴者が求めているのは「あなた（発信者本人）」ではない
  - 今は本人が全面的に前に出ている。そこをどう抑えるかがポイント
  - 自己満足で作るならそれでいいが、YouTube や SNS はそうではない
- **Instagram は伸びているのに YouTube が伸びていない理由**
  - Instagram と YouTube は視聴者がまったく違い、想像している世界線（世界観）も違う
  - そこをぴったり合わせられれば伸びる
- 別の目的があるなら言ってもらう
