# コンサル用メモ（ジャンル別の見立て）

ykkn 山内さんが感じた見立てを、今後のコンサルで使うために残しておくメモ。
手紙や資料には書かない内容も含む。**深く調べる前の仮説も含むので、使う前に裏付けを取ること。**

---

## 写真撮影・写真館（例：富士スタヂオ／photo studio cadeau）

- **YouTube とは相性があまり良くない**と見ている
  - 理由：YouTube はご年配の方に見られやすい媒体。写真館のお客様層（若い夫婦・子育て世代）とずれる
- **他の SNS なら顧客への展開ができる**。撮った写真や動画を SNS ごとに転用しやすい
- **TikTok に需要がありそう**（手紙には書かない）
  - TikTok は若い人向けなので、次の撮影と相性が良いのではないか
    - マタニティフォト
    - ウエディングフォト
  - まだ深くは調べていない仮説（2026年9月時点）

## はんこ・印章（例：大貫堂印房）

- 外国の方に向けた商品と、お城の印（御城印のようなもの）に需要があると見ている
- 発信していけば、新しいお客様が増えるきっかけになる可能性がある

## 塗装（例：公文塗装店）

- **YouTube とは少し相性が悪い**と見ている
- **他の SNS なら集客が見込めそう**
- ただし、どのくらい問い合わせが来るかはまだはっきり分からない。相談の場で、相手が何を求めているかを聞いてから対応を決める

## 農園・農業（例：音瀬計装の OTOSE FARM）

- いちごだけでなく他の野菜も育てているなら、そこから辿っての集客が見込めるかもしれない
- **YouTube とは割と相性が良い可能性がある**
- どう発信するかは目的次第（販売・観光農園・本業の技術PR など）。相談で目的を聞いてから決める

## 建築・外構など

- セミナーで話した戦略（視聴者理解 → ジャンルの俯瞰 → 無理なく続けられる体制）を一つずつやっていけば役に立てる、という見立て
