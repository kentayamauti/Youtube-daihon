## どの業種にも共通する考え方

- **目的によって戦略が変わる**。集客・顧客獲得・採用・再生数・販売など、まず相談で目的を聞く
- **視聴者が求めているのは「発信者本人」ではない**。本人が前に出すぎる作りは、伸ばしたいなら見直す
- **AI を露骨に使った発信はあまり好ましくない**
- **媒体ごとに視聴者が違う**
  - YouTube はご年配の方に見られやすい
  - TikTok は若い人向け
  - Instagram と YouTube は視聴者も、見る人が想像する世界観もまったく違う。そこを合わせると伸びる
- **事業者が多いジャンルは、お手本（モデリング先）を探す**と良い提案ができる
- YouTube は**撮影の体制と時間**（話し手・カメラマン・編集）が必要になることがある。続けられる体制かを考える
- セミナーで話した戦略：**視聴者理解 → ジャンルの俯瞰 → 無理なく続けられる体制**
