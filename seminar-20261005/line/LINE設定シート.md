## 4. ステップ配信（毎週1回・YouTubeのワンポイント）

場所：ホーム →「ステップ配信」→「作成」
- 開始条件：友だち追加
- 間隔：7日ごと
- 配信通数は月200通の無料枠に数えられます（友だちが増えてきたらライトプランを検討）

| 週 | テーマ | ねらい |
|---|---|---|
| 1週目 | サムネは「誰が・何を教えてくれるか」 | ワーク第1問の復習 |
| 2週目 | 自分のジャンルの「相場」の調べ方 | 成功ラインを知る |
| 3週目 | 競合の動画を見るときの3つの目線 | 俯瞰して見る |
| 4週目 | 「施工事例」だけでは見られない理由 | 会社目線 → 視聴者の悩み目線へ |
| 5週目 | 概要欄にHP・問い合わせ先を書く | 視聴者をお客さんに変える入り口 |
| 6週目 | クリック率10%でも喜べない理由 | 数値のワナ |
| 7週目 | BGM・画像の著作権、ここだけ注意 | 失敗を防ぐ |
| 8週目 | 続けられるペースの決め方 ＋ 個別相談のご案内 | 相談につなげる |

### 1週目
```

サムネは「誰が・何を教えてくれるか」

・誰が話すか（外構専門店が解説）
・何が分かるか（スタートガイド）

あなたの次の動画のサムネに、この2つは入っていますか？
「〇〇のプロが解説」＋「見たら分かること」を、まず一言で書いてみてください。
```

### 2週目
```
【YouTubeワンポイント #2】
自分のジャンルの「相場」を知る

YouTubeで自分のジャンルのキーワードを検索して、
同じくらいの規模のチャンネルの動画を10本見てみてください。
その再生数の真ん中くらいが、あなたのジャンルの「成功ライン」です。

陸上のジャンルなら1〜2万再生。
相場を知らないと、自分の動画が良いのか悪いのかも判断できません。
```
