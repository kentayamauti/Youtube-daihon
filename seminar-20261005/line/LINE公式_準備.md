# LINE公式アカウント 準備

目的：セミナー参加者とつながり続ける。QR コードでの申し込みは1回きりになりやすいので、LINE で継続的に連絡できるようにする。

- プラン：無料（コミュニケーションプラン）。月200通まで。参加者21名なら、一斉送信を月9回ほど送れる
- 手紙（PDF）と LP に、友だち追加の QR コードを入れる

## 1. アカウントを作る（ykkn 山内さんが行う）

1. 「LINE公式アカウント 作成」で検索し、LINEヤフー for Business の申し込みページから、手持ちの LINE アカウントでログインして作成する
2. 下の内容でプロフィールを設定する
3. 管理画面の「友だちを増やす」から、**友だち追加の URL**（`https://lin.ee/...`）を控える
4. その URL を Claude に伝える → 手紙の PDF と LP に QR コードを入れる

### プロフィール案

| 項目 | 内容 |
|---|---|
| アカウント名 | ykkn｜YouTube運用サポート |
| ステータスメッセージ | 会社のYouTube、何から始める？ |
| プロフィール画像 | LP やスライドで使っているアイコン |
| 業種 | ビジネスサービス（コンサルティング）など |

## 2. あいさつメッセージ（友だち追加されたとき自動で届く）

```
友だち追加ありがとうございます。
YouTubeセミナー講師の ykkn 山内です。

このLINEでは、
・YouTube運用のちょっとしたコツ
・次回セミナーのご案内
などを、ときどきお送りします。

「うちの会社の場合はどうだろう？」ということがあれば、このトークにそのまま気軽に送ってください。

個別相談のお申し込みはこちら
https://ykkn-youtube.com/
```

## 3. 一斉送信の予定（案）

送りすぎるとブロックされるので、セミナー後の1週間は3回まで。そのあとは月1〜2回。

気になったことがあれば、このトークにそのまま送ってください。
