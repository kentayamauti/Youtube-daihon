## 進め方（ロードマップ）

1. ✅ 台本とスライドの同期（v10 / v7）
2. ⬜ 仮打ち合わせ（来週）で【要確認】を確定 → 台本v11・スライドv8
3. ⬜ ワーク用サムネ画像（第1〜3問 A/B）を差し込み
4. ⬜ Googleフォーム作成（`form/create_form.gs` を実行）→ URLをLPに設定
5. ⬜ ykkn-youtube.com を取得し、LPを Cloudflare Pages で公開（`docs/hosting.md` の①〜③）
6. ⬜ LPのQRコードをスライドS37（特典）に掲載
7. ⬜ 本番（10/5）→ 申し込み対応

## 決定事項

- 個別相談：30分／通常30,000円 → 受講者特別価格15,000円（税込）。初回無料は無し
- LINE公式アカウント：無し（LPからLINE導線を削除）
- 独自ドメイン：`ykkn-youtube.com`
- 相談方法：オンライン（Zoom）／対面 どちらも可
- 特別価格の申し込み期限：セミナーから5日以内＝2026年10月10日（土）

## 確認待ちの事項

- 特商法表記に載せる事業者情報・支払い方法・キャンセル規定
- 台本の【要確認】箇所（Google検索の実演キーワード、ワークのサムネ素材、著作権・挫折の話を入れるか）

## セミナー後の使い回しについて

このLPは、次回セミナー用やメインのサイトとしてそのまま編集して使って問題ありません（ドメインもサーバーも自分のもの、デザインも自由に変更可）。
使い回すときに直す箇所：
- 「セミナー受講者限定」「15,000円・10/10まで」の文言（期限後は通常価格の案内に変更）
- ヒーローの文言（受講者向け → 一般の方向け）
- Googleフォームの説明文（フォームは同じものを使い続けてOK。回答もスプレッドシートに貯まり続ける）

おすすめの形：`ykkn-youtube.com` のトップをメインのLPにして、セミナーごとの案内は `ykkn-youtube.com/seminar/` のように下の階層に置く。
