# LINE配信づくり

`.company/共通ルール.md` を守る。担当は顧客関係（`.company/crm/CLAUDE.md`・`LINE発信の方針.md`）。

## 使うもの
| もの | 使い道 | ないとき |
|---|---|---|
| `.company/crm/配信/テーマ表_役立つ情報_半年24本.md` | 次のテーマを選ぶ | オーナーに一言でネタを聞く |
| `.company/crm/配信/NN_*.md` | 下書き・状態 | ― |
| LINE Messaging API（api.line.me・鍵は自動） | 友だち数・今月の送信数を読む | 「読めなかった」と書いて進める |
| `scripts/line_broadcast.py` | 配信（「状態：OK」のものだけ） | ― |

## 手順
1. **いまを確かめる**：`配信/` の状態（下書き／OK／配信済み）と、友だち数・今月の送信数（`/v2/bot/insight/followers`、`/v2/bot/message/quota/consumption`）。友だち×配信回数が月200通に近づいたら一言注意。
2. **次の1本を選ぶ**：テーマ表で状態が空の、いちばん若い番号。自己開示はオーナーとの会話から作る。
3. **下書き**：方針の「文の型」（1行目でつかむ・中身は1つ・最後に問いかけ、200〜400字、月1回だけLPへの案内）。身バレチェックの行を入れる。ファイル名は `NN_役立つ情報_テーマ.md`、`- 状態：オーナー確認待ち`。
4. **オーナーに見せる**：本文だけを、そのままコピーできる形で。直しがあれば直す。
5. **OKが出たら**：`- 状態：OK（日付 オーナー確認済み）・配信待ち` にして、テーマ表も更新。自動配信は main のファイルを読むので、main に入るまで（PRのMerge）をオーナーに頼む。
6. **配信後**：状態が「配信済み」になっているか、次の朝会で確かめる。

## 止まるところ
- オーナーOKの前に「状態：OK」にしない。配信スクリプトを手で動かすのは、オーナーが「今すぐ送って」と言ったときだけ。
