# おかんサムネイル

写真に **白文字＋太い黒フチ** の文字を、**画面いっぱいにパンパンに** 入れてサムネイルをつくる。

- 文字は画面の端ギリギリまで大きくする（上下は横幅いっぱい、縦書きは上から下までいっぱい）。
- 出力は **YouTubeサムネイル規格：1280x720（16:9）の JPEG・2MB未満**。写真が16:9でなくても中央で切り抜いて合わせる。`-o` に .png を指定しても .jpg で書き出す。

## 型は2つ（その都度決める）

| 型 | 見た目 | 向いている文 |
|---|---|---|
| `jouge`（上下） | 上に1行・下に1行の横書き。極太ゴシック。被写体は真ん中 | 「〇〇はもういかない／この作り方覚えて」みたいに2行で言い切る |
| `tate`（縦書き） | 右と左に縦書きの列。極太明朝。被写体は真ん中 | 短い言葉を4列くらいに分けられるとき。縦長の被写体 |

オーナーが型を言っていないときは、文の長さと写真（被写体がどこにあるか）を見て、どちらがいいか1行で提案して確認する。

## 手順

1. 写真と文字を受け取る（音声入力の誤変換は文脈で直す。自信がないところだけ確認）。
2. 型を決める。
3. スクリプトで作る：

```bash
S=.claude/skills/okan-thumbnail/make_thumbnail.py

# 上下
python3 $S jouge 写真.jpg --top "牛丼屋はもういかない" --bottom "この作り方覚えて" -o out/thumb.jpg

# 縦書き（--right / --left は「右の列から順に」何回でも指定）
python3 $S tate 写真.jpg --right "パックの" --right "まま焼け" \
    --left "もうコンビニ" --left "行かない" -o out/thumb.jpg
```

4. できた画像を自分で見て確認（文字が被写体に被りすぎていないか、はみ出していないか）してからオーナーに渡す。
5. 直しの指示があれば、オプションで調整して作り直す。

## 調整オプション

- 共通：`--fill`（文字色。例 `#FFE600` で黄色）、`--outline`（フチ色）、`--outline-ratio`（フチの太さ。既定 上下0.14／縦書き0.18）、`--font`（型の既定フォントを変えたいとき）、`--bold`（細いフォントを使うときだけ。0.03くらい）
- `jouge`：`--band`（1行の高さの上限、画面比。既定0.30。もっと文字を大きくしたいときに上げる）
- `tate`：`--side`（片側で使う幅、画面比。既定0.30）
- 文字の大きさは枠に合わせて自動。横書きは横幅いっぱい、縦書きは上から下までいっぱいになる。
  - 横書きで文字が少ないときは、少し横に伸ばして（最大1.3倍）幅を埋める。
  - 縦書きで文字が少ない列は字を大きく、多い列は細くして、どの列も上から下まで届かせる。

## フォント

参考サムネに合わせて、型ごとにフォントを固定している（`fonts/` に同梱。SIL Open Font License、商用利用OK。ライセンス文は `fonts/OFL.txt`）。

- 上下（`jouge`）：Noto Sans JP Black（極太ゴシック）
- 縦書き（`tate`）：Noto Serif JP Black（極太明朝）

上下を明朝にしたいなど、入れ替えたいときは `--font .claude/skills/okan-thumbnail/fonts/NotoSerifJP-Black.ttf` のように指定する。

## 注意

- サムネは外に出るもの。YouTubeに上げる前に必ずオーナーの確認を取る。
- 自分のチャンネルのサムネの企画（どんな文言にするか）は、チャンネル運営事業部の担当。この部屋は「文字を入れる作業」をする。
