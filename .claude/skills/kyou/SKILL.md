# 今日やること（朝会）

1. `business/README.md`、`business/部門/*.md`、`business/受付台帳.md`、直近の `business/日報/*.md` を読む。
2. 今日の日付と、近い期限（セミナー、特別価格の締め切り10/10など）を確認する。
3. 前日の「持ち越し」を最優先で拾う。
4. 優先度Aの中から、**オーナーが今日やるべきことを最大3つ**に絞る。選び方：
   - 期限が近い／お金・信用に関わる／本番に直結するもの
   - オーナーにしかできないもの（判断・連絡・作業）を優先。Claudeができるものは「Claudeが進めておくこと」に分ける
5. `business/日報/YYYY-MM-DD.md` を次の形でつくる（既にあれば更新）。

```
# 日報 YYYY-MM-DD（曜）｜（近い大事な予定まであと◯日）

## 今日やること（最大3つ）
1. 【部門】内容：具体的な一歩
2. ...

## Claudeが進めておくこと
- 【部門】内容

## 今日の受付
（仕分け人が追記）

## できたこと
## 持ち越し
```

6. オーナーには「今日やること3つ」と「Claudeが進めておくこと」を短く伝え、「Claudeの分を進めてよいか」を聞く。
7. 夜に「締め」と言われたら、できたこと・持ち越しを書き、部門ファイルと受付台帳の状態を更新する。
