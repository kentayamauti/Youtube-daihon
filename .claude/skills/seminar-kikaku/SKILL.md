# セミナー企画

`.company/共通ルール.md` を守る。担当はマーケティング（`.company/marketing/CLAUDE.md`）。前回の一式は `seminar-20261005/`、たたき台は `marketing/campaigns/2026-12_次回セミナー案.md`。

## 手順
1. **決める**：テーマ・対象・日時・会場（またはZoom）・定員・特典を、案から選んでもらう（1つずつ聞かず、まとめて1回）。
2. **段取り表**：開催日から逆算した表（告知開始・申し込み締め・スライド・印刷）を `campaigns/<日付>_<テーマ>.md` に。秘書のボードにも期限を入れる。
3. **集客**：LINE配信での先行案内（`line-haishin`）、紹介元への連絡文の下書き（送るのはオーナー）、告知ページの案（`ykkn-youtube.com/seminar/` の下。LPのファイルはオーナーに頼まれたときだけ変える）。
4. **中身**：前回のスライド・台本を土台に、テーマに合わせて直す。体験ワーク・個別相談への案内（特別価格と期限）も入れる。
5. **終わったら**：参加人数・相談の申し込み・アンケートを `campaigns/` に記録し、KPIを更新。

## 止まるところ
- 告知ページの公開・LINE配信・紹介元への連絡は、オーナーのOKの後。
