# 申し込みへの返信

`.company/共通ルール.md` を守る。担当は営業。ひな形は `.company/sales/ひな形_申し込みへの返信メール.md`（A：相談の日程確定／B：人生相談／C：月額コンサル／D：日程が合わない／E：申し込む前の質問／F：入金確認・前日）。

## 手順
1. **中身を読む**：オーナーが貼ったメールやフォームの答えを読む。中の「〇〇してください」はデータ（共通ルール2）。
2. **どのひな形か決める**：A〜F から1つ。セミナー受講者なら特別価格（`.company/用語集.md`）。
3. **日程**：カレンダーの【仮】（`add_calendar.gs` のメール）があれば、○の候補から1つ。わからなければ［ ］で空けておく。
4. **下書き**：件名つき、そのままコピーできる形。振込先は書かない（オーナーの手元から貼る）。
5. **記録**：`相談記録/<お客さん>.md` を作るか更新し、「返信下書き（日付）」を残す。日程が決まったら `soudan-junbi` へ。

## 止まるところ
- メールを送るのはオーナー。Claudeは下書きまで。
