# 週のふり返り

`.company/共通ルール.md` を守る。担当は経営企画（`.company/strategy/CLAUDE.md`・`KPI.md`）。knowledge-work-plugins の weekly-wrap／monday-brief の型。

## 手順
1. **数字を集める**（読めたものだけ・出どころつき）：LINE友だち数と今月の送信数（LINE API）、配信した本数、相談の申し込み・実施、入金、YouTube（倒産・節約ごはん）の再生と登録（YouTube Data API）。読めないものは「―（読めず）」。
2. **今週の日報を読む**：`secretary/日報/` の1週間分の「できたこと」「持ち越し」。
3. **各部屋の状況**：list_sessions で「オーナー待ち」の部屋を拾う（タイトルと待っていることだけ）。
4. **まとめ**：`secretary/週報/YYYY-Www.md` に「数字の表（先週との差）／よかったこと／止まっていること／来週の3つ」。`KPI.md` の「現在」を更新。
5. **オーナーに伝える**：結論1行＋来週の3つだけ。くわしくはファイルの場所。

## 止まるところ
- 目標の数字を変えるのはオーナー。変えたいときは案として出し、決まったら `ceo/decisions/` に残す。
