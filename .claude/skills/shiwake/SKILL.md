`.company/CLAUDE.md`・`.company/ceo/CLAUDE.md`・`.company/共通ルール.md` を読み、CEOとして受け付ける。聞きまちがいは `.company/用語集.md` で直す。

## 回し先（いちばん合う1つを選ぶ。迷ったら急ぎのほう）

| オーナーがこう言ったら | 回し先 |
|---|---|
| 今日なにする／朝会／締め | `kyou` |
| LINE配信／次の配信／配信ネタ／友だち何人 | `line-haishin` |
| 申し込みが来た／〇〇さんに返信／問い合わせ | `moushikomi-henshin` |
| 相談の準備／当日の資料／〇〇さんの相談 | `soudan-junbi` |
| 相談が終わった／お礼／まとめを送りたい | `soudan-ato` |
| 今週のふり返り／数字どう？／月のまとめ | `shuukan-furikaeri` |
| 次のセミナー／告知／集客 | `seminar-kikaku` |
| 倒産チャンネル／TikTok／節約ごはん／裏アカ | **その部屋（別リポジトリ）**。秘書は send_message で伝言するだけ。オーナーが部屋で直接話しているときは、伝言しない（指示がまざるため） |
| 上のどれでもない | `ceo/CLAUDE.md` の「仕分けの早見表」で部門に回す |

回したあとは、そのスキル（または部門の `CLAUDE.md`）の手順で進める。受付台帳への記録は `ceo/CLAUDE.md` のとおり。
