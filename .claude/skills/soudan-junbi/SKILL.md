# 個別相談の準備

`.company/共通ルール.md` を守る。担当は営業（`.company/sales/CLAUDE.md`・`個別相談30分の進め方.md`）。

## 使うもの
| もの | 使い道 | ないとき |
|---|---|---|
| `.company/sales/相談記録/<お客さん>.md` | これまでのやりとり・決まったこと | なければ `_template.md` で作る |
| お客さんのメール・申し込みフォームの答え | 悩み・目的 | オーナーに貼ってもらう |
| YouTube Data API（www.googleapis.com） | お客さんのチャンネル・同じジャンルの相場 | チャンネルがなければ「これから始める」前提 |

## 手順
1. **記録を開く**：相談日時・料金（通常／セミナー受講者価格）・時間（30分／1時間）・オンラインか対面か、を1行目に。
2. **事前メモ**：目的（集客／販売／広告収益）、相場（同じくらいの規模の10本の真ん中）、激戦区と空いている場所、いちばんの課題、次の一手の候補3つ。
3. **聞くこと＋仮の答え**：表で「聞くこと／予想される答え／仮の答え」。時間配分も書く（YouTube・SNSの話を中心に、ほかの悩みは短く）。
4. **当日資料（A4・1枚）**：`相談記録/<お客さん>/当日資料.html` → Chromium で PDF（`--print-to-pdf`、ファイルは file:// で開く）→ 画像で見た目を確かめる。中身は「今日決めること3つ／いちばん大事な話／すぐ使えるネタ／次の一歩」。お客さんにそのまま見せられる言葉で。
5. **オーナーに渡す**：PDFをファイルで送り、「直すところがあれば」と一言。

## 止まるところ
- 答えを先にメールで渡しすぎない（有料の相談で話す中身は資料と当日に）。
- 法律・税金・労務の判断はしない。専門家につなぐと書く。
