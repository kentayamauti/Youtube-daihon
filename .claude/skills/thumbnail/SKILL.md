# サムネイル作成部屋

写真に **白文字＋太い黒フチ** の文字を足して、1280x720 のサムネイルをつくる。

## 型は2つ（その都度決める）

| 型 | 見た目 | 向いている文 |
|---|---|---|
| `jouge`（上下） | 上に1行・下に1行の横書き。被写体は真ん中 | 「〇〇はもういかない／この作り方覚えて」みたいに2行で言い切る |
| `tate`（縦書き） | 右と左に縦書きの列。被写体は真ん中 | 短い言葉を4列くらいに分けられるとき。縦長の被写体 |

オーナーが型を言っていないときは、文の長さと写真（被写体がどこにあるか）を見て、どちらがいいか1行で提案して確認する。

## 手順

1. 写真と文字を受け取る（音声入力の誤変換は文脈で直す。自信がないところだけ確認）。
2. 型を決める。
3. スクリプトで作る：

```bash
S=.claude/skills/thumbnail/make_thumbnail.py

# 上下
python3 $S jouge 写真.jpg --top "牛丼屋はもういかない" --bottom "この作り方覚えて" -o out/thumb.jpg

# 縦書き（--right / --left は「右の列から順に」何回でも指定）
python3 $S tate 写真.jpg --right "パックの" --right "まま焼け" \
    --left "もうコンビニ" --left "行かない" -o out/thumb.jpg
```

4. できた画像を自分で見て確認（文字が被写体に被りすぎていないか、はみ出していないか）してからオーナーに渡す。
5. 直しの指示があれば、オプションで調整して作り直す。

## 調整オプション

- 共通：`--fill`（文字色。例 `#FFE600` で黄色）、`--outline`（フチ色）、`--outline-ratio`（フチの太さ、既定0.14）、`--bold`（文字を太らせる量、既定0.035）、`--font`
- `jouge`：`--band`（1行の高さ、画面比。既定0.22）
- `tate`：`--side`（片側で使う幅、画面比。既定0.27）、`--center`（短い列を上下中央に寄せる）
- 文字の大きさは枠に合わせて自動。文字数が少ない列ほど大きくなる。

## フォント

`fonts/` に太いゴシック（例：Noto Sans JP Black、源ノ角ゴシック Heavy）の `.ttf/.otf` を置くと自動でそれを使う。そのときは `--bold 0` にする。
置いていないときはIPAゴシックを太らせて使う。

## 注意

- サムネは外に出るもの。YouTubeに上げる前に必ずオーナーの確認を取る。
- 自分のチャンネルのサムネの企画（どんな文言にするか）は、チャンネル運営事業部の担当。この部屋は「文字を入れる作業」をする。
