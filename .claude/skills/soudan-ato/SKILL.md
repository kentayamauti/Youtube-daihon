# 相談のあと

`.company/共通ルール.md` を守る。担当は営業（月額につながるときはサービスも）。

## 手順
1. **聞く**：オーナーから、決まったこと・お客さんの反応・宿題を聞く（音声のメモや箇条書きでOK）。
2. **記録**：`相談記録/<お客さん>.md` に「当日話したこと／次の一手（本人／こちら）／月額の案内：した・しない（理由）」。
3. **お礼の下書き**：その日のうちに送る短い文（今日決めた次の一手を3行で）。当日資料のPDFを添えると書く。
4. **1〜2週間後の声かけ**：「その後どうですか？」の一言を下書きし、日報の該当日に予定として書く（押し売りしない）。
5. **数字**：`.company/strategy/KPI.md` の「相談の申し込み」「月額」の行を直す。入金があれば `admin/_template.md` の表に1行。

## 止まるところ
- 送るのはオーナー。月額の契約書・請求書は `admin/` のたたき台を使い、オーナーと専門家の確認後。
