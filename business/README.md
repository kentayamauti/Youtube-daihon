# Ykkn 事業本部（YouTube・SNS運用コンサルティング）

オーナー（山内）が指示を出し、**仕分け人**が担当部門に振り分け、各部門が実行する。これを毎日まわして事業を進める。

## 組織図

```
オーナー（山内）
   │ 指示（声・メモ・思いつき、何でもOK）
   ▼
仕分け人（受付・振り分け）──→ 受付台帳.md に記録
   │
   ├─ 経営企画部 …… 目標・数字・料金・時間配分・月次の振り返り
   ├─ マーケティング部 …… セミナー集客、LP、紹介元（塩谷会計事務所ほか）
   ├─ 営業部 …… 個別相談の運営、提案、契約・入金までのフォロー
   ├─ サービス部 …… 月額伴走サポート（週1ミーティング・Discord）
   ├─ 顧客関係部 …… LINE公式アカウント、紹介、次回セミナー案内
   ├─ 管理部 …… 請求・契約書・特商法・確定申告・副業規定
   └─ 研究開発部 …… 事例づくり、教材・ワークの改善、ノウハウの蓄積
```

## 毎日の流れ

1. **朝：今日やること**（`/kyou`）
   仕分け人が全部門のやることリストを見て、オーナーが今日やるべきことを**最大3つ**に絞って出す → `日報/YYYY-MM-DD.md`
2. **日中：指示を出す**（`/shiwake 指示内容`、または普通に話しかけるだけでもOK）
   仕分け人が受付番号をつけ、担当部門・優先度・期限・次の一手を決めて、部門のやることリストに入れる
3. **各部門が実行**
   Claudeでできること（文章・資料・LP修正など）はその場で進める。オーナーにしかできないこと（電話・支払い・判断）は「オーナー確認待ち」にする
4. **夜：締め**
   日報に「できたこと・持ち越し」を書く。持ち越しは翌朝の「今日やること」に回る

## 優先度のルール

- **A**：期限が3日以内／お金・信用に関わる／本番（セミナー・相談）に直結
- **B**：今週中に進めたい
- **C**：いつかやる（アイデア置き場）

## 大事な前提

- 動くのはオーナー1人（会社員との両立）。部署は「人」ではなく**時間と頭の切り替え**の単位。
- 1日に詰め込むのは最大3つ。続けられるペースが最優先（セミナーで伝えていることと同じ）。
- 外に出すもの（LINE一斉配信、LP公開、お客さんへの連絡）は、必ずオーナーが最終確認してから。
