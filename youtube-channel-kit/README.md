# YouTubeチャンネル運営キット（全チャンネル共通のひな形）

新しいチャンネルを立ち上げるとき・運営を自動化するときは、毎回このキットから始める。
**共通の部分（どのチャンネルでも同じ）** と **差し替える部分（チャンネル・ジャンルごとに違う）** を分けてある。

## 中身

| ファイル | 何に使う | 変える？ |
|---|---|---|
| `00_設計書ひな形.md` | 新チャンネルの設計書。コピーして `【差し替え】` を埋める | コピーして埋める |
| `01_ジャンル別の差し替え表.md` | ジャンルを選ぶと、差し替え部分の「初期値」がわかる | ジャンルが増えたら追記 |
| `02_リサーチ手順.md` | 立ち上げ前・毎週のリサーチのやり方（お手本分析／小規模ch調査／批判コメント／良い動画の定義） | 基本そのまま |
| `03_制作フロー.md` | 1本の作り方（サムネ→台本→編集→タイトル・概要欄・タグ）と台本の採点 | 基本そのまま |
| `04_自動化の状況.md` | どこまで自動でできるか・止まっているところ | 進んだら更新 |
| `tools/` | リサーチ用スクリプト（小規模チャンネル調査など） | 改良したら全チャンネルに効く |
| `channels/<番号>_<名前>/` | チャンネルごとの設計書・キャラ・データ・リサーチ結果 | チャンネルごと |

## 新しいチャンネルを始める手順

1. `channels/` に `<番号>_<仮の名前>/` を作り、`00_設計書ひな形.md` を `設計書.md` としてコピー
2. `01_ジャンル別の差し替え表.md` でジャンルを選び、`【差し替え】` の欄に初期値を入れる
3. `02_リサーチ手順.md` の「立ち上げ前リサーチ」を回し、結果を `research/` に置く
4. 結果を見て設計書の差し替え欄を直す（初期値のままにしない。数字で決める）
5. オーナーOK → `03_制作フロー.md` で1本目を作る

## 決まりごと（全チャンネル共通）

- 企画の良し悪しは「登録者が少ないチャンネルでも伸びているか」で判断する
- 外に出るもの（動画公開・コメント返信・SNS投稿）は、オーナーのOKを取ってから
- 1つのチャンネルで分かった「どのジャンルでも効くこと」は、このキットの共通部分に戻す
- 表記は「Ykkn 山内」
