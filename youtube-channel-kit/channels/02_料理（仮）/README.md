# 02 料理（仮）

- 状態：サムネ案だけ。チャンネル名・設計書はオーナー確認待ち
- 元になった企画：チャンネル運営事業部の決定「材料2つでチーズケーキ（ヨーグルト＋市販のチーズ蒸しパン）→ ココアを足すとティラミスにも」
- サムネの型（2026-10-12 調べた）：伸びている料理動画（syun cooking 登録者133万・270万回、HIRO SWEETS ほか）は
  - 料理の写真を画面いっぱいに2枚（全体＋断面）
  - 上と下に白い太字＋黒の太い縁取りを1行ずつ
  - 言葉は「市販のケーキ買うのやめた」「もう市販には戻れない」のような得する言い切り
  - キャラ・顔は出さない
- 参考にした動画：`library/@syuncooking/`、`library/@hiro_s_eets/`

## サムネの文字（2026-10-12 調べた）：夫手取り17万円の節約ごはん（@setuyakugohan、登録者74.7万・1〜2分の動画で中央値約18万回）

- 伸びた5本はほぼ同じ作り
  - 写真：木のテーブルに、できた料理（保存容器のまま）＋主役の材料の市販品のパッケージを並べる
  - 上の文字：「〇〇は全部これでいい」（5本中4本）。ほかは「居酒屋さんから教わった」（出どころ）
  - 下の文字：「痩せるのに1番旨い」（5本中4本）
  - 白い文字に細めの黒ふち＋影、左寄せ。材料の数・レンチンなど細かいことはタイトルに書き、サムネには書かない
- 文字の型：**上＝「（ジャンル）は全部これでいい」／下＝「（うれしいこと）のに1番旨い」**
- ひな形：`food` の `--style setsuyaku`
- チーズケーキの回の文字案：`plans/01_材料2つチーズケーキ/一覧_節約ごはん型.png`
