## 止まっていること

### コメントと動画ページが取れない

- クラウド環境から YouTube の動画ページを開くと、ロボット確認のページ（google.com）に飛ばされて止められる
- 環境に YouTube Data API 用の接続（www.googleapis.com）は設定されているが、
  キーではなくログイン用トークンの形で送られていて「認証エラー（401）」になる
- 直し方（どれか1つ）：
  1. 環境の設定で、YouTube Data API の **APIキー** を `key=` パラメータとして付ける形に直す（Google Cloudで「YouTube Data API v3」を有効にしたキー）
  2. オーナーのPCで Claude in Chrome を使い、コメントを読ませる
  3. オーナーがコメント欄をコピーして貼る

API キーが使えるようになれば、コメント収集・登録者数・再生数の取得がすべて安定して自動化できる。
