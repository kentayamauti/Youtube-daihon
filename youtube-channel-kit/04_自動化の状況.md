## 役割分担

| 取りたいもの | 担当 |
|---|---|
| 再生数・登録者・コメント | YouTube Data API（`www.googleapis.com`） |
| 台本（文字起こし） | YouTubeの文字起こし（`www.youtube.com`）。字幕がなければ Gemini API（`generativelanguage.googleapis.com`） |
| 分析・採点・台本づくり | Claude |

## APIキーの設定（環境のネットワークシークレット）

どちらも同じ形で1つずつ登録する。**シークレットは保存後に編集できない。変えるときは削除して作り直す。**

| 項目 | YouTube Data API | Gemini API |
|---|---|---|
| 種類 | Bearer | Bearer |
| 許可ウェブサイト | `www.googleapis.com` | `generativelanguage.googleapis.com` |
| カスタムヘッダー名 | `X-Goog-Api-Key` | `X-Goog-Api-Key` |
| プレフィックス | 空欄 | 空欄 |
| 値 | YouTube Data API v3 を有効にしたキー | Google AI Studio のキー（または Generative Language API を有効にしたキー） |

## 止まっていること

- なし（2026-10-12 時点）
- 気をつけること
  - Gemini は無料枠だと混雑（429/503）で止まりやすい。ツールは自動で別のモデルに回して待ち直す
  - YouTube の動画ページはロボット確認で止められる。文字起こしはアプリと同じ窓口から取っている
  - 環境のネットワーク設定で `www.youtube.com` を許可しておく必要がある
