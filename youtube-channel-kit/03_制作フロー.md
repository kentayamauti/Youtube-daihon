# 1本の制作フロー（全チャンネル共通）

順番は固定。チャンネルごとに変わるのは中身（設計書の差し替え欄）だけ。

## 1. サムネ（最初に作る）

- ここで「この動画は何を言い切るか」を決める。決まらない企画は作らない
- 型は設計書「6. 動画の形」。文字は2〜3かたまりまで、結論の言葉を1つ入れる
- 嘲笑顔・中身と違う煽りは使わない

## 2. 台本（プロット → 本編）

1. プロット：結論（サムネの言葉）／何が起きた（事実＋出典）／その回にしかない中身／考察（主張は1つ）／結論の言い直し
2. 本編：キャラの会話の型（相棒が質問 → メインが確かめる → 言い切る → 相棒がまとめる）
3. 採点：設計書「5. 台本の採点表」で80点以上。足りない項目を直してから次へ
4. 編集ソフト用に「話者名:セリフ」形式で書き出す（YMM4はこの形式で読み込める）

## 3. 編集

- 立ち絵・字幕・BGMを固定したテンプレプロジェクトを複製して使う
- 他人の映像・報道写真は使わない（図・表・自作素材で見せる）

## 4. タイトル・概要欄・タグ

- タイトル：サムネと同じ約束をする。主語（企業・商品名）を前半に
- 概要欄：設計書「8. 概要欄テンプレ」を埋める（出典を必ず入れる）
- タグ：主語になる企業・商品、話題、ジャンル語を5〜10個

## 5. 公開前チェック（オーナーOKの前に）

- [ ] サムネ・タイトルの約束を本編で果たしている
- [ ] 事実すべてに出典、意見は「〜と感じた」
- [ ] 台本採点80点以上
- [ ] 同じ話題が3本目になっていない／今日すでに1本出していない
- [ ] ジャンル固有のルール（設計書 7）を守っている

→ オーナーOKで公開。公開後48時間の再生数を記録する。
