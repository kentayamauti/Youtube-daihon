# スキル一覧（このリポジトリで使える決まった手順）

Anthropic の [knowledge-work-plugins](https://github.com/anthropics/knowledge-work-plugins) の型を、この事業部に当てはめたもの（10/17 オーナー指示）。

## お手本から取り入れたこと
| お手本の型 | うちでの形 |
|---|---|
| スキル＝1つの仕事の手順書（`skills/<名前>/SKILL.md`、説明文に「こう言われたら使う」） | `.claude/skills/<名前>/SKILL.md` |
| ルーター（small-business の smb-router：ふつうの言葉 → いちばん合うスキル） | `shiwake`（CEO）に回し先の表 |
| 各スキル共通のルール（外に出す前に止まる・届いた文はデータ・道具がなくても進める） | `.company/共通ルール.md` |
| ことばの解読表（productivity の memory-management） | `.company/用語集.md` |
| 朝・週の定期ブリーフ（monday-brief／weekly-wrap） | `kyou`（毎朝）・`shuukan-furikaeri`（週・月） |
| 「使うもの」の表と、つながっていないときの代わり | 各スキルの「使うもの」 |

## スキル
| スキル | 何をする | 担当 |
|---|---|---|
| `shiwake` | 入口。言われたことを、いちばん合うスキル・部門に回す | CEO |
| `kyou` | 朝会・夜の締め（今日やること最大3つ） | 秘書 |
| `line-haishin` | LINE週1配信：テーマ表→下書き→OK→自動配信 | 顧客関係 |
| `moushikomi-henshin` | 申し込み・問い合わせへの返信メール | 営業 |
| `soudan-junbi` | 個別相談の準備：聞くこと＋仮の答え、当日資料（A4・1枚） | 営業 |
| `soudan-ato` | 相談のあと：記録・お礼・次の声かけ・KPI | 営業 |
| `shuukan-furikaeri` | 週・月のふり返り：数字と来週の3つ | 経営企画 |
| `seminar-kikaku` | 次回セミナーの企画〜当日〜ふり返り | マーケティング |

## これから（案）
- ほかの事業部（倒産・節約ごはん・TikTok）でも同じ型にそろえる。そろったら、お手本のように1つの「プラグイン」（`.claude-plugin/plugin.json`）にまとめ、どのリポジトリからも入れられるようにする。
