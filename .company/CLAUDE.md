# YouTubeコンサル・セミナー事業部（.company）

Ykkn 山内の事業のうち、**YouTube・SNS運用のセミナーとコンサルティング**を担当する事業部。
（YouTubeチャンネル運営は別の事業部・別リポジトリ `youtube-channel-company`）

## 体制

```
社長／オーナー（山内）……指示を出す・最終判断をする
   │
CEO（Claude）……指示を受け付けて、担当部門に仕分ける（ceo/）
   │
   ├─ 秘書（secretary/）……朝の「今日やること」、日報、予定・期限の管理
   ├─ 経営企画（strategy/）……目標・数字・料金・時間配分、月次の振り返り
   ├─ マーケティング（marketing/）……セミナー集客、LP、紹介元、告知
   ├─ 営業（sales/）……個別相談の運営、提案、契約・入金までのフォロー
   ├─ サービス（service/）……月額伴走サポート（週1ミーティング・Discord）
   ├─ 顧客関係（crm/）……LINE公式アカウント、紹介、次回セミナー案内
   ├─ 管理（admin/）……請求・契約書・特商法・確定申告・副業規定・印刷
   └─ リサーチ・開発（research/）……事例、教材・ワークの改善、ノウハウ
```

各部門のフォルダには次がある。
- `CLAUDE.md`：その部門の役割・担当範囲・仕事の進め方（その部門として動くときに必ず読む）
- `やることリスト.md`：優先度つきのタスク
- `_template.md`：その部門の成果物の型

## 毎日の流れ

1. **朝**：秘書が「今日やること（最大3つ）」をつくる（`/kyou`）→ `secretary/日報/YYYY-MM-DD.md`
2. **日中**：オーナーの指示をCEOが受け付け、部門に仕分ける（`/shiwake`、または普通に話しかけるだけ）→ `ceo/受付台帳.md`
3. **各部門が実行**：Claudeができることはオーナーの OK の後に進める。オーナーにしかできないこと（連絡・支払い・判断）は「オーナー確認待ち」
4. **夜**：秘書が締める（できたこと・持ち越し）。大きな決定は `ceo/decisions/` に残す

## 優先度

- **A**：期限3日以内／お金・信用に関わる／本番（セミナー・相談）に直結
- **B**：今週中
- **C**：アイデア置き場

## 共通ルール

- 動くのはオーナー1人（会社員と両立）。1日に詰め込むのは最大3つ。
- 外に出るもの（LP公開、LINE配信、お客さんへの連絡、SNS投稿）は、必ずオーナーの OK を取ってから。
- 表記は「Ykkn 山内」。秘密情報（パスワード・トークン）はチャットに出させない。
- セミナーの制作物は `seminar-20261005/` にある（台本・スライド・LP・LINE・配布物）。
- **YouTube動画を調べたら、必ず動画ライブラリ（`youtube-channel-kit/library/`）に保存する。調べる前にまず `library/index.csv` を見て、調べ済みなら調べ直さない。**（2026-10-12 オーナー決定・全部門）
- **役割：オーナー＝最終判断、Claude＝ディレクター。分からないこと・うまく進まないことは、勝手に進めずオーナーに質問する。分かるところだけ先に進める。**（2026-10-12 オーナー決定・全部門）
