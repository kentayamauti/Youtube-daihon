  • 同じ動画が「利用者さん募集」と「職員募集」の両方に効きます。Instagramは、動画の切り抜きを載せるだけの片手間でOK。

最初の3本（あらすじ）

1

ほまれの家の1日に密着（10〜15分）

朝の来所 → 作業 → お昼 → 帰りまで。顔を出せる方だけ、手元や後ろ姿でもOK。最後に「見学はこちら」。

2

はじめての方へ：見学から利用開始までの流れ（5〜8分）

電話 → 見学 → 体験 → 利用開始。ご家族・相談員さんが知りたい順に。

3

ここで働くということ：職員の1日（8〜12分）

サービス管理責任者・支援員の仕事と考え方。採用の入口にもなります。

この先の候補：利用から一般就労へ進んだ方のお話／工賃・お給料のこと／よくある質問（休んでもいい？どんな人がいる？）

ホームページと採用

  • 動画の概要欄からホームページへ。見学・採用の窓口をそこにまとめる
  • 採用は「面接に来るだけ」にしない。応募の前に小さな課題（成果物）を出してもらう → 本気の人が残る
  • 今の職員さん全員で性格診断（16タイプなど） → 「ほまれの家に合う人」の仮説を作り、応募者にも受けてもらう
診断は判断の材料の1つ。それだけで決めない。

かかるもの・編集

  • かかるのはカメラ1台だけ（まずはスマホでも可）。カメラはほかの用途にも使えます
  • 編集はAIで短くできる時代です
    • 撮影はほまれの家さん → 編集は Ykkn 山内（月額サポート）
    • または、ご自分でAI（Claude Code など）を試す

わかったこと → ほまれの家さんの攻め方

  1. 長い密着がいちばん強い：「利用者さんの1日」（10〜15分）が1〜2万回。月1本でも届く形です → 1本目にする。
  2. 「流れ」と「その先」も見られる：利用の流れ（1.2万）・一般就労へのインタビュー（1.7万）。ご家族・相談員さんが知りたいことです。
  3. 職員の1日は採用に効く：サービス管理責任者の密着（7,800）。「ここで働く姿」が先に見えると、合う人が応募してきます。
  4. まだ空いている：どのチャンネルも登録者は1,000人前後。きちんと作れば、地域でいちばんになれる場所です。
