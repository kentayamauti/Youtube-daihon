## 案1：レイ ── 旅するAIキャラ　★おすすめ

| 項目 | 内容 |
|---|---|
| 名前 | レイ（Rei） |
| 設定 | 「AIだから、どこへでも行ける」。世界や日本の街角を毎日1か所たずねる、20代後半の旅人キャラ |
| プロフィール文（案） | AIで生まれた旅人 ✈️ 毎日ひとつ、世界のどこかへ。／AI生成キャラです（中の人あり）／新作の壁紙はリンクから |
| 口調 | さっぱりしたタメ口。短め。絵文字は1投稿1つまで。「〜だよ」「〜かも」 |
| 発信テーマ（3本柱） | ①今日の行き先（風景＋レイ）②街のミニ知識（1行トリビア）③「次どこ行く？」フォロワーにリクエストを聞く |
| 見た目の方向 | 黒髪ショートボブ、ベージュのトレンチコート＋小さなリュック。服装は旅先で少し変わるが顔・髪は固定。写真風よりも「イラスト寄りのリアル」でAIらしさを隠さない |
| 売りやすいもの | 旅先ごとの壁紙セット、季節の「旅カレンダー」、旅行系アフィリエイト（PR表記） |

**おすすめの理由**
- AIであること自体が設定の一部なので、「AI生成」の表示が自然で、実在の人と間違われにくい
- 風景がメインなので、恋人っぽい見せ方に頼らずに伸ばせる。安全で、凍結リスクも低い
- 「次どこ行く？」で、フォロワーがネタを出してくれる。1日15分でも続けやすい
- 壁紙・カレンダーにしやすく、旅行案件ともつながる

## 案2：ミオ ── 喫茶店めぐりのキャラ

| 項目 | 内容 |
|---|---|
| 名前 | ミオ（Mio） |
| 設定 | 季節の飲み物とレトロ喫茶が好きな、20代半ばの社会人キャラ |
| 口調 | やわらかいです・ます調まじり。「〜でした☕」 |
| 発信テーマ | ①今日の一杯（架空の喫茶店）②季節の話題 ③おやすみ前のひとこと |
| 見た目の方向 | 明るめの茶髪ロング、ニット・カーディガン系。暖色の店内の光 |
| 売りやすいもの | 季節の壁紙、喫茶店風のイラスト集 |

- よいところ：やさしい雰囲気で、保存されやすい
- 気をつけるところ：日常系は「実在の女の子っぽさ」に寄りやすいので、AI表示をより目立たせる必要がある。似たアカウントが多く、埋もれやすい

## 案3：ナギ ── 夜ふかしゲーマーのキャラ

| 項目 | 内容 |
|---|---|
| 名前 | ナギ（Nagi） |
| 設定 | ネオンの街に住む、ゲームとガジェット好きの20代キャラ |
| 口調 | ゆるいタメ口。「それな」「今日もやるか〜」 |
| 発信テーマ | ①今夜の一枚（ネオン・サイバー風景）②遊んでるゲーム・ガジェットの話 ③夜の雑談 |
| 見た目の方向 | 銀髪ウルフカット、オーバーサイズのパーカー、ヘッドホン。青紫のネオン |
| 売りやすいもの | PC・スマホ壁紙、ガジェット案件 |

- よいところ：壁紙の需要が高く、ガジェット案件とつながる
- 気をつけるところ：ゲームの話題は版権キャラ・画面を使えないため、ネタが限られる。夜の投稿が中心で、生活リズムとかみ合いにくい
