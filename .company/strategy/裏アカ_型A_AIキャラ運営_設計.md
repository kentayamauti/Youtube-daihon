## 1. ひとことで

美女GO!! で作ったオリジナルAIキャラを「AIキャラだと明かしたうえで」SNSで育て、
ファン向けコンテンツ（画像集・有料プラン）で稼ぐ。
あわせて「AIキャラアカウントの伸ばし方」を本業（SNS運用コンサル）の事例ネタにする。

## 2. 守る線（ここを外れるならやらない）

| ルール | 理由 |
|---|---|
| プロフィールに「AI生成キャラ」と必ず書く。投稿にも #AIイラスト / #AIart 等 | 実在女性と誤認させると詐欺・規約違反。Xは誤認させる合成メディアを制限 |
| 実在の女性になりすましたDM営業・課金誘導をしない（いわゆる「裏アカ女子」型） | 詐欺・景表法・特商法のリスク。凍結とオーナーの信用失墜 |
| 実在の人物（芸能人・知人）に似せない | 肖像権・パブリシティ権 |
| 性的コンテンツはやらない。未成年に見える見た目にしない | プラットフォーム規約・法令。決済代行も止まる |
| 返信は「案をつくる」まで。送信は人が確認して手動 | 誤爆・炎上防止（スクショの仕組みと同じ方針） |
| 本アカ（Ykkn 山内）とは端末・メール・電話番号を分ける | 身バレ防止。ただし事例として出すかはオーナー判断 |

## 3. キャラ設計

- 決めること：名前、世界観（例：カフェ店員／旅好き／ゲーマー など1つ）、口調、投稿テーマ3本柱、NGワード
- 見た目は美女GO!! で固定（同じキャラに見えるよう、顔・髪型・色を固定した生成設定を保存）
- 「中の人」は出さない。キャラとして日常・季節・テーマ写真を投稿する

## 4. チャネルと役割

```
X（入口：毎日1〜2投稿・画像中心）
 ├─ Instagram／Threads（同じ画像の再利用・別ファン層）
 └─ プロフィールリンク
      ├─ LINE公式（キャラ名義・週1配信／新作のお知らせ）
      └─ 販売先（FANBOX／Fantia／BOOTH など。全年齢プランのみ）
```

## 6. 運用フロー（1日15〜30分）

1. 週1回まとめて：美女GO!! で1週間分の画像を生成 → オーナーが選ぶ
2. Claudeが投稿文の下書き（キャラ口調）→ オーナーOK → 予約投稿

4. 週1：数字を見る（フォロワー・インプレッション・保存数・販売数）
