# SNSから売上直結マニュアル（要点・社内参照用）

- 原本：`SNSから売上直結マニュアル.pdf`（全9ページ）
- 採用日：2026-10-05（受付 No.003）
- 位置づけ：経営企画の**考え方の土台**。相談に来る会社さん向けの資料（事前診断・提案書・相談の進め方）は、この7 STEPの順番と言葉で組み立てる。
- 注意：原本をそのままお客さんに渡す・LINEで配るのは、出どころと使ってよい範囲をオーナーが確認してから。外部調査の数字（Sprout Social など）を資料に使うときは出典を書く。

## ひとことで

**SNSで「注目」を集め、リストで「関係」を育て、提案で「売上」に変える。**
SNS は入口。利益は「SNS → リスト獲得 → 教育 → 相談 → 成約 → 継続フォロー」の導線全体でつくる。

## 7 STEP

| STEP | やること | 相談企業の資料で見るところ |
|---|---|---|
| 0 | 売上の式を決める：接触数 × 登録率 × 相談化率 × 成約率 × 単価 ＝ 売上 | 5つの数字の現状値が出せるか。出せないところが最初の課題 |
| 1 | 買ってほしい顧客を1人まで絞る（属性 → 悩み1つ → タイトルに対象者の言葉） | 「誰でも見たい投稿」ばかりになっていないか |
| 2 | SNSの役割は「もっと知りたい」まで（投稿4タイプ：問題発見／専門性／信頼／次行動） | 4タイプの配分。次行動（リストへ移す）投稿があるか |
| 3 | フォロワーを自社リスト（LINE・メール）へ移す。特典は「商品と同じ悩み」で作る | 特典の公式：ターゲット固有の悩み × すぐ使える成果物 × 商品につながる次の課題 |
| 4 | 登録直後の5通（特典 → よくある失敗 → 解決の全体像 → 事例 → 次の行動） | 登録後に何も届いていない／いきなり売り込んでいないか |
| 5 | 相談・購入へのオファーを1つに絞る。CTAは固定し、流入元を記録 | 高単価なら無料相談・診断、低単価なら商品ページ・お試し |
| 6 | 買わなかった98%を育てる（事例・FAQ・セミナー案内・対象者/対象外） | 継続配信があるか |
| 7 | 再生数ではなく売上KPIで改善（到達・登録率・相談化率・成約率・獲得価値） | 再生数↓でも登録率・相談率・成約率↑なら改善。逆なら集める相手がズレている |

例：月10,000人に届き、3%がLINE登録、10%が相談、20%が成約、単価30万円 → 180万円。

## 売れない原因の4つの切り分け（診断で使う）

1. **購入対象者ではない**：伸びるテーマに寄せすぎ → 対象者を明記した投稿を増やす
2. **対象者だが悩みが違う**：投稿テーマと商品課題がつながっていない → 商談・インタビューから悩みの言葉を拾う
3. **悩みはあるが商品が欲しくならない**：理解・信頼・証拠不足 → 事例・比較・プロセス・対象者/対象外
4. **商品は欲しいが売り方が悪い**：価格・提案・タイミング・申込導線 → 相談率と成約率を分けて測り、ボトルネックだけ直す

## 30日実行プラン（伴走サポートの最初の1か月の型に使える）

| 期間 | やること | 完了条件 |
|---|---|---|
| 1〜3日 | 売上の式を作る | 到達→登録→相談→成約→単価の現状値を記録 |
| 4〜7日 | 顧客を絞る | 理想顧客・悩み・買う理由・買わない理由を整理 |
| 8〜10日 | 登録特典を作る | 商品につながるチェックリスト／診断／テンプレート |
| 11〜14日 | LINE導線を作る | 5通の教育シナリオ＋相談CTA |
| 15〜21日 | 投稿を7本出す | 広い投稿4本＋ターゲット限定投稿3本 |
| 22〜25日 | 数字を比較 | 再生数だけでなく登録率・相談率を見る |
| 26〜28日 | ボトルネック改善 | 最も落ちている1工程だけ修正 |
| 29〜30日 | 次月の仮説を決める | テーマ・CTA・特典のABテストを1つ選ぶ |

## 運用会社に頼む前の発注チェック（相談企業にそのまま聞ける質問）

- ゴールに売上・利益または商談数が入っているか
- フォロワー数・再生数だけを成果指標にしていないか
- 誰を集めるアカウントか合意しているか
- LINE／メールなどSNS外への導線も設計対象か
- 投稿別の登録数・相談数・成約数を追えるか
- 「伸びた投稿」だけでなく「売れた投稿」を分析しているか

## まず始める4つ（相談の最後の「次の一手」に使う）

① 売上の式を決める ② ターゲット限定投稿を1本出す ③ LINEなどの登録先を用意する ④ 登録後の5通を作る
