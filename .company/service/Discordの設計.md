# Discordの設計（月額コンサル）

- お客さん1社につき、1つのサーバー（または1つのカテゴリー）。ほかのお客さんの情報が見えないようにする。
- 参加者：お客さん側（担当者）＋ Ykkn 山内。

## チャンネル（部屋）の構成

| 部屋 | 使い方 |
|---|---|
| #はじめに | ルールと、返信の目安・ミーティングの日時を固定表示 |
| #質問 | なんでも質問。1つの質問に1つのスレッド |
| #企画・サムネ相談 | 企画案・サムネ案を貼る。「どっちがいい？」もOK |
| #数字の報告 | 週1回、アナリティクスのスクショを貼る（ミーティング前日まで） |
| #ミーティングまとめ | 毎回のまとめ（決めたこと・宿題・次回日時）。Ykknが書く |
| #資料 | 渡した資料・テンプレート置き場 |

## ルール（#はじめに に貼る文）

```
このサーバーは、◯◯さん専用の相談部屋です。

・質問は #質問 に、いつでもどうぞ。1つの質問ごとにスレッドを立ててください。
・お返事の目安は48時間以内（土日祝を除く）です。急ぎのときは「急ぎ」と書いてください。
・週1回のミーティングは、毎週［◯曜◯時］です。
・ミーティングの前日までに、#数字の報告 にアナリティクスのスクショを貼ってください。
・ここでのやりとりは、お互い外に出しません。
```

## Ykkn側の決めごと

- 通知は「メンション」と「#質問」だけオンにして、本業中は見ない。返信は1日1回（夜）にまとめる。
- 同じ質問が2回来たら、#資料 にまとめて置く。
