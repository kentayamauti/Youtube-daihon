# AIで回る会社キット（Ykkn 山内のしくみのひな形）

Ykkn 山内が、会社員をしながら5つの事業を Claude Code で回している「しくみ」を、小さな会社・お店・事業所でもそのまま使える形にしたもの。
世の中でいう「AI業務OS」（仕事を、状態・担当・期限・決まり・記録で整えるしくみ）の、いちばん小さい版。

## なぜ要るのか
- 「AIを入れたのに、仕事が変わらない」会社が多い。原因は、AIに聞く“言い方”ではなく、**仕事の置き場所と決まりがないこと**。
- このキットは、AIが毎日同じ場所を見て、同じ決まりで動けるようにする「土台」。

## 中身（ひな形/ フォルダ）
| ファイル | 役目 | 図でいうと |
|---|---|---|
| `CLAUDE.md` | 会社の説明と、AIへの基本の決まり | 土台 |
| `共通ルール.md` | 外に出す前に止まる・数字は出どころつき など | 承認ゲート |
| `受付台帳.md` | たのんだことを番号・状態・担当・期限で1行ずつ | 表で管理 |
| `やることリスト.md` | 優先度つきの仕事 | 表で管理 |
| `日報/` | 毎日の「今日やること3つ」と、できたこと | 記録 |
| `決めたこと/` | 大きな決定を1件1ファイルで | 記録 |
| `.claude/skills/` | 決まった手順（朝会・仕分け・ふり返り） | 学習ループ |

## 30分で始める5ステップ
1. Claude Code を入れて、空のフォルダ（GitHub の非公開リポジトリがおすすめ）を作る
2. `ひな形/` の中身を全部コピーする
3. `CLAUDE.md` の【 】を自分の会社の言葉で埋める（AIに「質問しながら埋めて」と頼んでもよい）
4. 毎朝「今日なにする？」と話しかける → 朝会スキルが日報を作る
5. 思いついたら、ふつうの言葉で「〇〇したい」と話す → 仕分けスキルが受付台帳に書いて進める

## 続けるコツ
- 1日にやることは3つまで。
- AIが外に出すもの（メール・投稿・お客さんへの連絡）は、必ず人が「OK」してから。
- うまくいかなかったことも `決めたこと/` や `共通ルール.md` に1行足す。これが「学習ループ」。足すほどAIが会社に合っていく。
