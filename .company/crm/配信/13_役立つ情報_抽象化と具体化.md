- オーナーの話（11/8）：抽象化＝大きな視点で俯瞰。リンゴ→果物→食べ物、ベクトル（赤い・丸い）。単品だけ見るのは間違い、ジャンル全体と比べる。具体化：本質は同じだが別の動画に見えるように（→野菜→トマト）、サムネ・タイトル、コンセプトからズレない。NGは工程ごとに出すと直しやすい。方向性が合わなければ作業工程を文章にしてもらう。

```
【YouTubeワンポイント】
伸びる企画は「抽象化 → 具体化」で作る

「抽象化する力が大事」
一度は聞いたことがあると思います。

なぜ大事なのか。
それは、「なぜこの商品・この動画が売れているのか」が
わかるようになる力だからです。

以前お話しした「俯瞰する」を覚えていますか？
抽象化とは、まさにそれ。
物事を、大きな視点でとらえることです。

■ 抽象化（大きくとらえる）
リンゴ → 果物 → 食べ物

ここで大事なのは、"向き"があること。
リンゴ → 赤い
リンゴ → 丸い
どの向きで見るかで、答えが変わります。

よくある間違いは、
伸びている動画「1本だけ」を見てしまうこと。

正しくは、
リンゴ・オレンジ・バナナ → 果物 → 食べ物
のように、ジャンル全体の傾向と、
その1本を比べて見ることです。

■ 具体化（自分の企画に落とす）
次に、見つけた共通点を、自分の企画にします。

リンゴ → 果物 → 食べ物 → 野菜 → トマト

本質は同じでも、ぱっと見は別の動画に見えるように。
それを、サムネとタイトルに落としこみます。
ただし、チャンネルのコンセプトからズレない範囲で。

抽象化がズレていると、具体化もズレます。

■ チームで動画を作っている方へ
「この企画はNG」とだけ言われても、
どこを直せばいいのかわかりません。

でも、作業のどの部分がダメなのかがわかれば、直せます。

例）「企画の作り方は良い。
　　でも、ほかのチャンネルとかぶっているので、
　　そこだけ直しましょう」

もし外注さんやスタッフと方向性が合わないと感じたら、
まずは「作業の手順」を文章にしてもらいましょう。
どこでズレているのかが、すぐに見えてきます。
```
