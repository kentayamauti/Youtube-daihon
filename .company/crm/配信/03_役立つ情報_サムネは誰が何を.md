# 配信 03｜役立つ情報｜サムネは「誰が・何を教えてくれるか」

- 種類：役立つ情報（テキスト。画像は文面OK後に作る）
- 状態：オーナー確認待ち
- テーマ表 #02

```
【YouTubeワンポイント】
サムネは「誰が・何を教えてくれるか」

伸びている動画のサムネを並べて見ると、
共通しているのはこの2つです。

① 誰が話しているか
（例：「〇〇のプロが解説」）

② 見たら何が分かるか
（例：「失敗しない〇〇の選び方」）

逆に伸びにくいのは、
「〇〇やってみた」「〇〇について」のように、
見る前に"得られるもの"が分からないサムネ。

視聴者はサムネを見る0.5秒で、
「これは自分のための動画か？」を判断しています。

あなたの次の動画のサムネ、
「誰が」と「何が分かるか」は入っていますか？

よければサムネをこのトークに送ってください。一言コメントします。
```

## 別案（10/11 秘書の部屋で作ったもの・どちらか一方を使う）

```
【YouTubeワンポイント】
サムネは「誰が・何を教えてくれるか」

サムネを作るとき、
かっこいいデザインから考えていませんか？

実は、見る人がサムネで知りたいのは
たった2つだけです。

① 誰が話しているのか
② この動画を見たら、何が分かるのか

たとえば工務店さんなら
×「施工事例紹介 vol.12」
○「大工歴20年が教える 後悔しない窓の選び方」

デザインが上手じゃなくても、
この2つが一瞬で伝われば、クリックされます。

ためしに、自分のサムネを1枚だけ見て
「誰が・何を」が3秒で分かるか、
チェックしてみてください。

分かりにくいサムネがあれば、
このトークに送ってもらえたら一言アドバイスします。
```
