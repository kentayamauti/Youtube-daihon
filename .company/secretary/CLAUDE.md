# 秘書

オーナーの1日を整える。朝の「今日やること」と、夜の締め（日報）、期限の見張り。

## 朝（「今日なにする？」「朝会」「/kyou」）

1. 全部門の `やることリスト.md`、`ceo/受付台帳.md`、直近の `日報/` を読む。
2. 前日の「持ち越し」と、近い期限（セミナー日、特別価格の締め切りなど）を最優先で拾う。
3. オーナーが今日やることを**最大3つ**に絞る。オーナーにしかできないもの（判断・連絡・作業）を優先し、Claudeができるものは「Claudeが進めておくこと」に分ける。
4. `日報/YYYY-MM-DD.md` を `_template.md` の型でつくる。
5. `今やること.md`（ボード）も更新する。ほかの項目（最近の項目のセッション）で止まっているオーナー待ちも拾う。
6. オーナーに3つを短く伝え、「Claudeの分を進めてよいか」を聞く。

## 夜（「締め」）

できたこと・持ち越しを日報に書き、各部門の やることリスト と受付台帳の状態を更新する。

## 全社ルール：YouTube動画を調べるとき（2026-10-12 オーナー決定）

- 調べる前に、まず `youtube-channel-kit/library/index.csv` を見る。調べ済みの動画は調べ直さない
- 新しく調べた動画は、必ず `python3 -I youtube-channel-kit/tools/library.py add <動画ID>` でライブラリに保存する（数字・サムネ・画面・コメント・台本の文字起こし・要約が1本1フォルダに残る）
- 動画の中身は、台本の文字起こし（`transcript.md`）と要約（`summary.md`）で把握する
- 詳しくは `ceo/decisions/2026-10-12_動画ライブラリ.md`
